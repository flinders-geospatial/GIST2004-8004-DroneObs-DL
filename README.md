# GIST2004/8004 drone observation practicals

Two Colab practicals for GIST2004/8004 on low-altitude oblique drone video:
object detection, tracking and line counting. No deep learning background
assumed.

1. **Train, track and count.** Fine-tune a YOLO detector on drone imagery,
   then track and count vehicles crossing a line in a supplied clip.
   [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/flinders-geospatial/GIST2004-8004-DroneObs-DL/blob/main/drone_observation_yolo_colab.ipynb)
2. **Count vehicles in the class footage.** Load the model saved in the
   first practical and run it on the clips the class flew over two
   intersections near the campus.
   [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/flinders-geospatial/GIST2004-8004-DroneObs-DL/blob/main/drone_observation_field_footage_colab.ipynb)

I hand out the course files by web link during class, so they aren't in this
repository. [`COLAB_SETUP.md`](COLAB_SETUP.md) has the file list and my
class-day checklist.
